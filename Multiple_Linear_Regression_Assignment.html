3 3. Multiple Linear Regression

3.1 3.1 Model specification

The dependent variable is Fertility.

The independent variables are Agriculture, Examination, Education, Catholic, and Infant.Mortality.

The regression model is:

\[ Fertility = \beta_0 + \beta_1 Agriculture + \beta_2 Examination + \beta_3 Education + \beta_4 Catholic + \beta_5 Infant.Mortality + \epsilon \]

3.2 3.2 Fit the multiple linear regression model

# Fit multiple linear regression model
model <- lm(Fertility ~ Agriculture +
              Examination +
              Education +
              Catholic +
              Infant.Mortality,
            data = swiss)

3.6.1 Interpretation of R-squared

R-squared measures the proportion of variation in fertility explained by the independent variables included in the regression model.

For example, an R-squared of 0.80 would indicate that 80% of the observed variation in fertility is explained by the fitted model.

Adjusted R-squared accounts for the number of explanatory variables and is useful when evaluating models containing multiple predictors.

3.6.2 Overall model significance

The F-test evaluates whether the explanatory variables jointly provide evidence of a linear relationship with fertility.

The hypotheses are:

\[ H_0: \beta_1=\beta_2=\beta_3=\beta_4=\beta_5=0 \]

\[ H_1: \text{At least one } \beta_i \ne 0 \]

# Extract F-statistic and p-value
model_f <- summary(model)$fstatistic

f_value <- unname(model_f[1])
f_p_value <- pf(
  f_value,
  model_f[2],
  model_f[3],
  lower.tail = FALSE
)

cat("F-statistic:", f_value, "\n")
## F-statistic: 19.76106
cat("Overall model p-value:", f_p_value, "\n")
## Overall model p-value: 5.593799e-10
if (f_p_value < 0.05) {
  cat("Conclusion: Reject the null hypothesis.\n")
  cat("The regression model is statistically significant.\n")
} else {
  cat("Conclusion: Fail to reject the null hypothesis.\n")
  cat("The regression model is not statistically significant at 5%.\n")
}
## Conclusion: Reject the null hypothesis.
## The regression model is statistically significant.

4 4. Regression Diagnostics

Regression diagnostics help determine whether the assumptions of multiple linear regression are reasonably satisfied.

The major assumptions examined in this assignment are:

  1. Linearity.
  2. Normality of residuals.
  3. Homoscedasticity (constant error variance).
  4. Absence of serious multicollinearity.
  5. Independence of errors.
  6. Absence of excessively influential observations.

4.1 4.1 Linearity assumption

Linearity means that the expected value of the dependent variable is a linear function of the model predictors.

We use a residuals-versus-fitted plot to investigate this assumption.

plot(model, which = 1)

Interpretation:

  • A random distribution of residuals around zero supports the linearity assumption.
  • A clear curved pattern may indicate a nonlinear relationship.
  • A systematic pattern suggests that the model may be missing important structure.

4.2 4.2 Normality of residuals

The normality assumption states that the regression errors are approximately normally distributed for the usual small-sample t and F inference.

We examine a histogram, a Q-Q plot, and the Shapiro-Wilk test.

# Calculate model residuals
residuals_model <- residuals(model)

# Histogram
hist(residuals_model,
     main = "Histogram of Regression Residuals",
     xlab = "Residuals",
     col = "lightblue",
     border = "black")

# Normal Q-Q plot
qqnorm(residuals_model,
       main = "Normal Q-Q Plot of Residuals")

qqline(residuals_model,
       col = "red",
       lwd = 2)

4.2.1 Shapiro-Wilk normality test

Hypotheses:

\[ H_0: \text{Residuals are normally distributed} \]

\[ H_1: \text{Residuals are not normally distributed} \]

# Perform Shapiro-Wilk test
shapiro_result <- shapiro.test(residuals_model)

shapiro_result
## 
##  Shapiro-Wilk normality test
## 
## data:  residuals_model
## W = 0.98892, p-value = 0.9318
# Interpret the test
if (shapiro_result$p.value > 0.05) {
  cat("Fail to reject H0: There is insufficient evidence of non-normality.\n")
} else {
  cat("Reject H0: There is evidence that residuals are not normally distributed.\n")
}
## Fail to reject H0: There is insufficient evidence of non-normality.

A p-value greater than 0.05 indicates that the test does not find sufficient evidence against normality. It does not prove that the residuals are normally distributed.

4.3 4.3 Homoscedasticity assumption

Homoscedasticity means that the variance of the regression errors remains approximately constant across different fitted values.

We use a residual plot and the Breusch-Pagan test.

# Residuals versus fitted values
plot(fitted(model),
     residuals_model,
     main = "Residuals vs Fitted Values",
     xlab = "Fitted Values",
     ylab = "Residuals",
     pch = 19,
     col = "blue")

abline(h = 0, col = "red", lwd = 2)

4.3.1 Breusch-Pagan test

Hypotheses:

\[ H_0: \text{The error variance is constant} \]

\[ H_1: \text{The error variance is not constant} \]

# Breusch-Pagan test using an auxiliary regression
bp_auxiliary <- lm(
  I(residuals_model^2) ~ Agriculture +
    Examination +
    Education +
    Catholic +
    Infant.Mortality,
  data = swiss
)

# Calculate the test statistic
bp_statistic <- nrow(swiss) *
  summary(bp_auxiliary)$r.squared

# Calculate p-value using chi-square distribution
bp_p_value <- pchisq(
  bp_statistic,
  df = 5,
  lower.tail = FALSE
)

cat("Breusch-Pagan LM statistic:", bp_statistic, "\n")
## Breusch-Pagan LM statistic: 5.851087
cat("Breusch-Pagan p-value:", bp_p_value, "\n")
## Breusch-Pagan p-value: 0.3209795
if (bp_p_value > 0.05) {
  cat("Fail to reject H0: No significant evidence of heteroscedasticity.\n")
} else {
  cat("Reject H0: Evidence of heteroscedasticity exists.\n")
}
## Fail to reject H0: No significant evidence of heteroscedasticity.

Interpretation:

  • If the p-value is greater than 0.05, we do not find sufficient evidence of non-constant error variance.
  • If the p-value is below 0.05, there is evidence of heteroscedasticity.

The test above uses the classical Breusch-Pagan auxiliary-regression approach.

4.4 4.4 Multicollinearity

Multicollinearity occurs when two or more independent variables are strongly linearly related.

It can increase the standard errors of regression coefficients and make individual effects difficult to distinguish.

We use the Variance Inflation Factor (VIF).

\[ VIF_i = \frac{1}{1-R_i^2} \]

Where \(R_i^2\) is obtained by regressing one independent variable on all the other independent variables.

# Independent variables
predictors <- swiss[, c(
  "Agriculture",
  "Examination",
  "Education",
  "Catholic",
  "Infant.Mortality"
)]

# Function to calculate VIF without an additional package
calculate_vif <- function(data) {

  vif_values <- numeric(ncol(data))

  names(vif_values) <- names(data)

  for (i in seq_along(data)) {

    other_variables <- data[, -i, drop = FALSE]

    auxiliary_model <- lm(
      data[[i]] ~ .,
      data = other_variables
    )

    r_squared <- summary(auxiliary_model)$r.squared

    vif_values[i] <- 1 / (1 - r_squared)
  }

  return(vif_values)
}

# Calculate VIF values
vif_results <- calculate_vif(predictors)

vif_results
##      Agriculture      Examination        Education         Catholic 
##         2.284129         3.675420         2.774943         1.937160 
## Infant.Mortality 
##         1.107542

Interpretation guidelines:

  • VIF close to 1: Little multicollinearity.
  • VIF between 1 and 5: Usually acceptable.
  • VIF above 5: Possible multicollinearity concern.
  • VIF above 10: Serious multicollinearity concern.

These are common guidelines rather than absolute statistical rules.

4.5 4.5 Influential observations and outliers

An influential observation is an observation that can substantially affect the estimated regression coefficients.

Cook’s distance helps identify potentially influential observations.

# Calculate Cook's distance
cooks_distance <- cooks.distance(model)

# Plot Cook's distance
plot(cooks_distance,
     type = "h",
     main = "Cook's Distance",
     xlab = "Observation",
     ylab = "Cook's Distance")

# Reference threshold
abline(h = 4 / nrow(swiss),
       col = "red",
       lty = 2)

# Identify observations above the reference threshold

# Predict fertility
predicted_fertility <- predict(

)

predicted_fertility
##        fit      lwr      upr

The prediction provides an estimated fertility value for a province with the specified predictor values.

The prediction interval represents uncertainty for an individual future observation, rather than just uncertainty about the mean response.

6 6. Results and Interpretation

The multiple linear regression model examines the joint association between fertility and five socioeconomic variables.

The coefficient estimates indicate the direction and magnitude of the conditional relationships, while the p-values help assess statistical significance.

The R-squared and adjusted R-squared values indicate how much variation in fertility is explained by the model.

The F-test evaluates whether the predictors are jointly statistically significant.

Regression diagnostic tests and plots are used to evaluate the suitability of the model assumptions.

7 7. Conclusion

This assignment demonstrated how multiple linear regression can be applied to investigate the relationship between a dependent variable and several independent variables.

The Swiss Fertility dataset was used to estimate a regression model with fertility as the dependent variable and agriculture, examination, education, Catholic population percentage, and infant mortality as explanatory variables.

The analysis covered descriptive statistics, correlation, visualization, regression estimation, coefficient interpretation, hypothesis testing, model goodness of fit, and regression diagnostics.

The diagnostic analysis is important because a statistically significant regression model is not automatically an appropriate model. Its assumptions must also be examined.

Finally, the results describe associations in historical observational data. They should not be interpreted as proof that the explanatory variables cause changes in fertility.
