Including Plots

You can also embed plots, for example:

# Create temperature data
temperature <- seq(0, 360, by = 20)

# Create pressure data
pressure <- c(
  0, 0, 0, 0, 0, 0, 0, 0,
  5, 10, 18, 32, 55, 95, 155,
  245, 375, 560, 805
)
# Generate scatter plot
plot(
  temperature,
  pressure,
  main = "Temperature vs Pressure",
  xlab = "temperature",
  ylab = "pressure",
  pch = 1
)

Note that the echo = FALSE parameter was added to the code chunk to prevent printing of the R code that generated the plot.

Understanding the plot() function

temperature: Data for the X-axis

pressure : Data for the Y-axis

main: Graph title

xlab: X-axis label

ylab: X-asis label

pch = 1 : Displays hollow circular points

You can customize the graph using:

pch = 19: Solid circles.

col = “blue”: Blue points.

cex = 1.2: Increases point size.
